# ddii_scopus

**ddii_scopus** — программный комплекс на Python/PyQt6 для управления блоком **ДДИИ (Датчик Дозы Ионизирующего излучения)**, анализа сигналов и эмуляции измерительных процессов.
Программа реализует модульную архитектуру, включает GUI, средства логирования, обмена по Modbus, визуализации осциллограмм и сохранения данных в HDF5.

---

## 1. Назначение

Система предназначена для:

* Управления аппаратным модулем МПП по **Modbus RTU/TCP**;
* Захвата, отображения и анализа сигналов с аналоговых каналов (A/B);
* Управления высоковольтным источником (HVIP);
* Конфигурирования параметров измерений и фильтров (трапецеидальных, пороговых);
* Эмуляции работы МПП без подключения аппаратуры;
* Сохранения потоков данных в формате **HDF5** и ведения логов измерений.

## 3. Основные модули

| Модуль                   | Назначение                                                         |
| ------------------------ | ------------------------------------------------------------------ |
| **Engine**               | Управление измерениями, взаимодействие с устройством, запуск задач |
| **Emulator**             | Эмуляция сигналов и данных без физического устройства              |
| **Main_Config**          | Конфигурирование приложения и параметров устройства                |
| **Main_Hvip**            | Управление высоковольтным источником                               |
| **Main_Serial**          | Подключение по Modbus RTU/TCP                                      |
| **Main_Trapezoid**       | Настройка фильтрации сигналов                                      |
| **Main_Graph_Widget**    | Отображение осциллограмм в реальном времени                        |
| **Main_Waveform_Viewer** | Просмотр сохранённых файлов HDF5                                   |
| **src/**                 | Вспомогательные библиотеки, логика обмена, событийная система      |

## 5. Установка и запуск

```bash
python -m venv .venv
source .venv/bin/activate     # Linux/macOS
# или .venv\Scripts\activate  # Windows

pip install -U pip
pip install -e .
```

Запуск:

```bash
python main.py
```

Приложение загружает главный интерфейс.
Конфигурация берётся из `config/config.ini`.

## 7. Форматы данных

* Потоки данных сохраняются в формате **HDF5** (`*.hdf5`) в `log/data_flow/`.
* Каждый сеанс сохраняется в отдельную директорию с меткой времени.
* Формат именования:

  ```
  log/data_flow/YYYY-MM-DD_HH-MM-SS-fff_<номер>/
  ```
* В директории создаётся файл с именем, аналогичным каталогу.

## 8. Логирование

Все логи разделены по подсистемам:

| Каталог          | Назначение                        |
| ---------------- | --------------------------------- |
| `log/debug/`     | Общие отладочные логи             |
| `log/emulator/`  | Эмулятор сигналов                 |
| `log/serial/`    | Работа по последовательному порту |
| `log/data_flow/` | Потоки измеренных данных (HDF5)   |

Настройки логгера — `src/log_config.py`.

## 12. Отладка

### Типичные проблемы

| Симптом                    | Возможная причина             | Решение                                   |
| -------------------------- | ----------------------------- | ----------------------------------------- |
| Нет данных на графике      | Неверный COM-порт или ID      | Проверить конфигурацию                    |
| Ошибка Modbus CRC          | Несовпадение параметров порта | Проверить скорость, паритет               |
| Не записываются файлы HDF5 | Нет доступа к `log/`          | Проверить права и место на диске          |
| GUI не отображается        | Ошибка в PyQt6                | Проверить установку и версии зависимостей |
