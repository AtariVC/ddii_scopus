# Старые виджеты

Здесь лежит то, что заменено новыми виджетами. Код оставлен для справки —
приложением он не используется и в импортах не участвует.

| файл | чем заменён |
|---|---|
| `run_meas_widget.py` / `.ui` | `run_control_widget.py` — объединён с run_flux |
| `run_flux_widget.py` / `.ui` | `run_control_widget.py` — объединён с run_meas |

Что при слиянии убрано осознанно (по согласованию):

* «Порог запуска, lsb» — это то же самое, что «Тригер, lsb»; поле одно;
* выбор фильтра осциллограмм (`comboBox_filter`);
* тест CSA (`checkBox_enable_test_csa`);
* калибровка АЦП (`pushButton_calibr_acq` → `mpp_cmd.calibrate_ACQ()`).

Логика самих циклов (ACQ / HH / ACQ_Peak) перенесена без изменений.
