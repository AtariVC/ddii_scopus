
## 🧩 **Инструкция по генерации и сбору документации проекта**
---

### 1️⃣ Установи зависимости

Активируй виртуальное окружение и установи нужные пакеты:

```bash
source .venv/bin/activate
pip install pdoc beautifulsoup4
```

---

### 2️⃣ Сгенерируй HTML-документацию

Перейди в корень проекта (там, где находится папка `ddii_scopus`) и выполни:

```bash
pdoc -o docs ddii_scopus
```

После выполнения появится структура:

```
docs/ddii_scopus/
```

---

### 3️⃣ 📖 **Посмотреть документацию локально**

#### Вариант A — через встроенный сервер

```bash
pdoc -p 9999 ddii_scopus
```

После запуска открой в браузере:

```
http://localhost:9999
```

#### Вариант B — напрямую из файлов

Открой в браузере файл:

```
docs/ddii_scopus/index.html
```

(двойной клик по файлу или `Ctrl+O → выбрать index.html`).
